# Bank Loan Approval and Creditworthiness Predictor

Predicts whether a bank loan applicant is creditworthy (Approved / Rejected)
using historical financial, employment, and credit-history feature.

## Project Structure
```
bank-loan-predictor/
├── dataset/
│   ├── loan_approval_dataset.csv     # raw data
│   └── clean_loan_dataset.csv        # generated by preprocess.py
├── notebooks/
│   └── exploratory_analysis.ipynb
├── src/
│   ├── preprocess.py                 # cleaning, encoding, feature engineering
│   └── train.py                      # trains + compares 3 models, saves the best
├── api/
│   └── app.py                        # FastAPI /predict endpoint
├── models/
│   └── best_loan_model.pkl           # winning model + scaler + metadata
├── requirements.txt
├── README.md
└── project_paper.md
```

## Setup
```bash
cd bank-loan-predictor
pip install -r requirements.txt
```

## 1. Preprocess the data
```bash
cd src
python preprocess.py
```
Cleans the raw CSV, strips whitespace, fills missing values, encodes
`education`/`self_employed`/`loan_status`, and engineers a
`total_asset_value` feature (sum of the four asset columns).

## 2. Train and compare models
```bash
python train.py
```
Trains **Logistic Regression**, **Random Forest**, and **SVM**, prints
Accuracy / Precision / Recall / F1-Score and the confusion matrix for each,
and saves the model with the best F1-Score to `models/best_loan_model.pkl`.

## 3. Run the API
```bash
cd ..            # back to project root
uvicorn api.app:app --reload --port 8000
```
Then POST to `http://localhost:8000/predict`:
```json
{
  "no_of_dependents": 2,
  "education": "Graduate",
  "self_employed": "No",
  "income_annum": 4200000,
  "loan_amount": 15000000,
  "loan_term": 10,
  "cibil_score": 680,
  "residential_assets_value": 8000000,
  "commercial_assets_value": 2000000,
  "luxury_assets_value": 3000000,
  "bank_asset_value": 4000000
}
```
Response:
```json
{
  "prediction_label": 1,
  "status": "Approved",
  "approval_probability": 0.925
}
```

## Known caveat
`cibil_score` is highly correlated with `loan_status` in this dataset,
which produces unusually high F1-scores (~0.98). Treat this as a property
of the dataset, not proof the pipeline generalizes to real-world data —
worth flagging explicitly in the final paper rather than presenting the
metric at face value.
